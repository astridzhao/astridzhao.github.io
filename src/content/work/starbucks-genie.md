## From idea to deployed application

I built an AI-powered drink customization application to explore how multiple AI agents could collaborate in a consumer-facing workflow.

The project connects a React front end with backend services and data storage, using CrewAI, Supabase, Railway, and Vercel. Along the way, I worked through API integration, asynchronous jobs, and deployment challenges across the client and server.

The experience made me more thoughtful about what users actually need from an AI feature: clear outcomes, predictable interactions, and responsive software.
