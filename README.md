# Astrid Zhao — Portfolio

Personal site of Astrid (Ziyin) Zhao, built with [Astro](https://astro.build/) and deployed through GitHub Pages.

## Site sections
- Home: introduction and featured work
- Work: professional and side project case studies
- About: background, interests, and community
- Resume: current web-based experience and skills

## Development

```bash
npm ci
npm run build
npm run dev
```

Add project Markdown files in `src/content/work/` with the required frontmatter fields defined in `src/content/config.ts`.

Project descriptions are high-level and intentionally exclude proprietary systems, code, and sensitive regulatory information.
